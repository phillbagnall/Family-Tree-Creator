Your trees are saved to GitHub, so they're the same on every device. Connect this device once to get started.

Where do I get the access key?
  1. Whoever looks after the trees (the repository owner) opens GitHub → New fine-grained token.
  2. Repository access: Only select repositories → choose the trees repository.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate the token and paste it here. Keep a copy somewhere safe for the next device.
